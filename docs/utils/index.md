# Utils 工具集

YSS UI Utils 聚焦中后台高频基础能力，减少业务代码重复实现。

## 推荐顺序

1. 先看 [formatDate](/utils/format) 统一日期展示格式
2. 再看 [downloadBlob](/utils/download) 处理文件下载
3. 最后根据场景使用认证、剪贴板与 URL 能力

## 能力地图

- 日期格式化：`formatDate`
- 文件下载：`downloadBlob`、`handleBlobResponse`
- 认证相关：`clearAuthInfo`
- 剪贴板：`copyToClipboard`
- URL 解析：`getUrlData`
